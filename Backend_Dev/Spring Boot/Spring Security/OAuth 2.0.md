**OAuth 2.0** is an **authorization framework** that enables applications to obtain limited access to user accounts on an HTTP service (like Google, GitHub, Facebook, etc.).  
It allows users to grant **third-party applications** access to their information **without sharing their credentials (username/password).**
## Roles in OAuth 2.0

|Role|Description|Example|
|---|---|---|
|**Resource Owner**|The user who owns the data|You|
|**Client (Application)**|App requesting access to user data|Travel App|
|**Authorization Server**|Verifies identity & issues tokens|Google OAuth Server|
|**Resource Server**|Hosts the protected resources|Google Calendar API|
